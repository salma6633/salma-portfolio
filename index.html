GRADUATION PROJECT (PFE) · 2025 / 2026 Huawei Tunisia (Client: Ooredoo)

RoamGuard: AI-Driven Inbound & Outbound Roaming Experience and Revenue Optimization

Presented by: Salma Labidi Academic Supervisor: CHAREFEDDINE Mohamed Ali Corporate Supervisor: Khyari Oussema
Problem
Roaming quality was historically managed with fragmented dashboards, manual Excel reports, one-off snapshots, and reactive complaint-driven action. Limits: detected too late, no root-cause insight, no dynamic week-to-week follow-up, and inability to quantify revenue losses in TND.
RoamGuard Solution
An automated weekly data pipeline addressing 4 core Business Objectives (BO1–BO4) using the CRISP-DM methodology:
  • BO1 (Forecasting): Inbound quality forecasting via LightGBM (MAE 0.0245, R² 0.9245) beating XGBoost, Ridge, LSTM & TFT. High/Medium/Low risk tiers for 117 partners.
  • BO2 (Detecting): Unsupervised outbound anomaly detection with ensemble Isolation Forest + One-Class SVM (AND-vote) (Wasserstein 0.931, Composite 0.789). 41/108 flagged (32 Critical, 9 High) and routed as NOC tickets.
  • BO3 (Pricing): Revenue loss quantification in Dinars via counterfactual regression using XGBoost (MAE ~0.905 TND) with 95% Bootstrap CI & SHAP. 117/130 partners confirmed with ~72,000 TND cumulative loss.
  • BO4 (Recommending): Traffic steering optimization using HiGHS Linear Programming (+11.4% avg weighted-quality gain).
Production Stack
Automated weekly Apache Airflow pipeline (file sensors, validate >=10k sessions, clean & prep, push to DB, drift & alerts, unit tests) + React/FastAPI web application + Grafana real-time telemetry monitoring + BI (~60 monitoring panels) across Inbound, Outbound, QoE, and Commercial metrics + Private offline RAG & ReAct AI Assistant (Ollama) with GPU tuning (~10s response time).

Internship · Geospatial AI Jul – Aug 2025 Armada Delivery Solutions (Kuwait · Remote)

Predictive Geocoder & Spatial Vectorization Pipeline

Student: Salma Labidi Academic Supervisor: Mr. Rammah Ali Head of Engineers: M. Bouraoui
Challenge
Last-mile urban logistics in Kuwait (Salmiya, Hawalli, Farwaniya) faced high delivery failure rates due to unstandardized, colloquial Arabic and English addresses lacking postal codes, previously forcing dispatchers to manually input raw GPS coordinates into the Ettijahet platform.
Solution
Followed CRISP-DM & Scrum methodologies to engineer a hybrid geocoding system:
  • Spatial Preparation: Handled geographical density imbalance using Kernel Density Estimation (KDE) sample weighting and hierarchical Geohash spatial bucketing.
  • Text Normalization & NLP: Typo-tolerant address normalization via RapidFuzz, dual-representation vectorization combining character n-gram TF-IDF with multilingual Sentence-Transformers embeddings.
  • Hybrid ML Architecture: XGBoost regression coupled with FAISS vector search for sub-linear similarity candidate lookup, slashing tail localization error at critical 20–200m thresholds.
Production
Deployed as a high-throughput Python REST API (POST /geocode, POST /eta) integrated directly into the production Ettijahet Directions platform (Express.js backend) to compute dynamic ETA, driving distance, and coordinate confidence scores.

HireHero: AI Agent for Application Screening & Strategic HR Platform

Challenge
Talent acquisition teams are overwhelmed by high volumes of unstructured candidate CVs across conflicting formats (scanned documents, images, multi-column PDFs), creating severe screening delays, subjective evaluation bias, and difficulty objectively validating technical competencies against complex job requirements.
Solution
Engineered an intelligent end-to-end recruitment platform combining OCR, semantic search, and autonomous LLM agents:
  • OCR & Document Parsing: Automated ingestion pipeline using EasyOCR and OpenCV image preprocessing to parse and extract structured competencies, work trajectories, and education from heterogeneous CV documents.
  • Semantic Candidate Matching: Dual vectorization via Sentence-BERT (SentenceTransformers) indexed with FAISS for sub-linear similarity ranking between candidate profiles and job descriptions.
  • Fine-Tuned LLM & RAG Agent: Fine-tuned local LLaMA 3 via LoRA (Low-Rank Adaptation) integrated with an autonomous LangChain RAG agent, allowing recruiters to ask natural-language queries, compare candidates, and assess qualifications.
  • Automated Quiz Generator: Dynamic generation of targeted technical assessments calibrated to candidate experience levels and specific role requisites.
Production
Packaged as an interactive Python / Flask web application with local ChromaDB & FAISS vector persistence and private GPU-accelerated inference, ensuring complete candidate data privacy and eliminating cloud API latency.
